# 更新日志

## v2.11.1 (2026-10-27)

- **重构**
  - Admin控制器和Buid控制器进行拆分，仅内部结构重构，URL/HTTP方法/权限校验与响应结构一律不变。
  - 构建/后台/OAuth的SQL下沉到独立仓储与服务，多写事务统一走TransactionManager；行为与响应不变。

- **修复**
  - 镜像仓库不支持扫描时， 审计记录状态不再写入'unknown'，改为按构建状态归一为成功/失败/待处理，与提交状态一致。

- **优化**
  - nginx upstream 启用 resolve + Docker 内置 DNS，php-fpm副本扩缩容或容器重建后自动更新IP，多副本下失败请求达到阈值后，实现被动故障转移。
  - docker-compose 集中日志滚动配置；nginx 升级至 1.28 并收敛容器能力,新增探活端点与 gzip。
  - 删除已迁入数据库的连接配置；删除配置模板(settings.example.php)。

## v2.11.0 (2026-10-24)

- **新增**
  - 镜像仓库类型可选：Harbor（默认）或标准 OCI 仓库（registry:2 等），单实例二选一，两种类型不并存。标准仓库不提供漏洞扫描，相关页面会自动隐藏对应列与操作。
  - 新增 `POST /api/build/{path}/registry-sync` 回写端点：CI 推送镜像后向 Glue 报告结果，不要求仓库具备扫描能力，标准仓库也能记录推送结果并回写 Git 状态。
  - 集成服务契约端点下发镜像仓库的类型与地址，CD 等消费方不再手工维护一份本地配置，仅维护用户名与密码；端点不可用时回退本地配置。
  - 查询仓库 tag 返回 tag 详情而非仅名称， 另带扫描结论。
  - tag 端点支持分页返回 ，两者都不带则维持原有的数组响应不变，CD 的仓库同步等既有消费方无需改动。
- **变更**
  - 映射、构建与部署数据、后台页面中的镜像仓库字段由 `harbor_repository` 更名为 `registry_repository`，自动迁移把旧值搬到新字段后删除旧字段。
  - `scan-sync` 与 `registry-sync` 共用同一套回写逻辑，差别只在是否读取扫描结果；`scan-sync` 定位为 Harbor 存量入口。
  - 回写的审计记录不再只认最终成功的流水线：CI 报告过推送但最终失败或未完成的，审计照常保留，镜像产物仍只在流水线成功时记录、也只有成功才被当作推送事实。
  - 契约下发的仓库类型与地址只提供给持有「Harbor 查询」权限的凭据。
  - 标准仓库的健康检查改为探测 `/v2/`；两种仓库类型共用同一份连接配置，切换类型只改访问协议。
  - 两个回写端点的审计分别标记 `harbor-scan` / `registry-sync`，审计页两种都识别，历史记录仍可见。
  - 镜像仓库查询权限的 scope 由 `harbor.read` 重命名为 `registry.read`；存量 token 在启动时自动迁移，无需重签。。
- **修复**
  - 仓库路径支持两段以上，此前仅限两段。
  - 查询镜像仓库的接口对非法的项目名与仓库名返回 400 与提示。
  - commit status 回写按各平台认可的状态值发送：失败统一为 `failure`，无扫描结论时按流水线结果推导。
  - 标准仓库密码为空时按匿名访问，不再发送认证信息，默认用户名不再导致匿名拉取失败。
  - 项目列表的项目名一律返回文本：纯数字首段不再被转成数字，与文档声明的结构一致。
  - 老版本 SQLite 不支持删列时，删除改名后的旧字段改为尽力而为：只记告警、不再中断启动迁移，残留的旧字段无害。
  - 两处缺失的页面文案不再直接显示翻译键本身（登录 token 生成失败提示、隐含权限下拉）。
  - 带参数的文案渲染正确：此前占位符的花括号会留在句子里，还会误替换句中同名的单词。
  - Harbor 版本探测在网络异常时不再回退探测 v1 端点：此前一次超时就会被固化成「v1」并缓存一小时。
  - 平台连接地址允许只填 `host[:port]`：Harbor 按 https 归一、标准仓库按 http 归一，不再因为地址缺少 scheme 而请求失败。
  - Jenkins 健康检查改为按响应状态码判定连通性：状态码低于 500 才算可达。

## v2.10.0 (2026-10-17)

- **新增**
  - 平台连接配置与 OIDC / SSO 客户端白名单迁入数据库，由两个后台页面管理；凭据加密存储，明文永不下发。
  - 构建模式只保留独立 CI，各 Git 平台内置 CI 拆为独立开关，旧合并格式自动迁移。
  - GitHub Actions 可作为拉取式 CI 来源，接入自动发现与构建模式。
  - 支持 Bitbucket / GitCode 作为自定义 Git 平台。
  - 拉取式 CI 失败按 HTTP 语义返回：资源不存在（404）、服务不可达（502）、服务不可用（500）；API token 调用沿用同一语义。
  - 自动发现结果区分「成功 / 部分失败 / 全部失败」，并列出失败的平台。
  - 平台连接卡片默认折叠，点标题栏展开。
  - 映射必须声明构建源：新增时未带 `build_provider` 返回 400，显式传空值拒绝，命中空构建源的映射在构建时拒绝执行，不再兜底为 Jenkins（此前遗留的空构建源映射需编辑补上 CI）。
  - 编辑映射改为与原行合并后保存，只传需要修改的字段时不再把其余字段清空。
  - 未指定构建源的映射在映射列表、拓扑图、项目下拉中统一显示为「未指定构建源」，不再标注为 Jenkins，也不会从列表中消失。
- **修复**
  - 托管类型按 base_url 域名判定，修正 gitlab.com 被误判为自建。
  - Harbor、Git 平台、Jenkins 不可达时如实报「平台不可达」，不再表现为「无数据 / 无分支 / Job 不存在」。
  - API token 调用中「资源不存在」与「服务不可用」不再被一律压成 502。
  - 关闭某平台 CI 时，其 active 映射同步降为待启用，重开不再隐式复活。
  - 构建记录加载失败显示后端原因而非裸状态码；自动刷新失败保留已有表格。
  - 扫描提示不再数秒即消失，连续提示不再互相覆盖。
  - 映射的新增 / 编辑改为只写单行，不再「读全表 → 改一条 → 全量回写」，并发编辑不再互相覆盖；批量写入包进事务，空输入拒绝执行而非清空整表。
  - 编辑映射时 `job_name` 传空不再等同于删除该条，改为返回 400。
  - OpenAPI 补录路由兼收 POST、规范只写 GET 的端点（`main` / `build` / `git` / `harbor` 各列表端点与 `/oauth/userinfo`），并补上缺失的 `custom_builds`、`operation_logs`、`pipelines/{id}/resolve-tag`。
  - commit status 回写不再回显上游原始异常（可能含内网 URL），改为返回可安全展示的摘要与 HTTP 状态码。
  - CI 凭证无效 / 权限不足（401 / 403）如实报出，不再被归为「服务不可用」。
  - 自动发现不再把 GitHub / Gitea 的 5xx 当作「没有项目」，失败与平台名一并汇总提示。
  - Jenkins 不可达的报错不再携带内网请求地址，明细只写入日志。
  - GitCode 仓库识别为 SaaS——此前 SaaS 主机列表用了 GitCode 并不使用的域名。
  - 未指定构建源的映射不再被 Job 列表过滤掉、不再被按 Jenkins 筛出、也不会在关闭某 CI 时被误降为待启用。
  - 自动发现不再因同名但无构建源的映射存在而跳过该项目，其构建源仍可被补全。
  - 未命中映射的 path 仅在 Jenkins 已启用时才走 Jenkins 直连，否则直接拒绝，不再一律假定为 Jenkins Job。
  - 点「立即执行」后，一整句的执行结果不再撑破平台连接卡片的四列布局：长结果就地折行，不再挤瘪相邻卡片。
  - `BuildController::report()` 按上报 path 取映射改为统一走 `MappingManager::resolveMapRow()`，不再自行遍历全表，构建、scan-sync 与上报三处不再解析到不同行。
  - 从构建日志提取的 tag 需符合 Docker tag 规范（`[A-Za-z0-9_][A-Za-z0-9._-]{0,127}`）：不符合的取值（如未展开的 `${TAG}`）会被丢弃；尾随标点连同日志句末句号一并清洗（`v1.0.` 还原为 `v1.0`）。两类脏值都不再带着去 Harbor 校验，报错不再指向 Harbor。
  - 移除 `BUILD_TIMEOUT`：此前没有任何代码读取该环境变量，而文档暗示调大它能放宽 Jenkins 触发超时（实际是 `JenkinsService` 里固定的 30 秒）；FAQ 与失败点表已改为如实写出各家 CI 的超时值。
- **优化**
  - nginx、php-fpm、定时任务拆为独立容器，Web 层可独立水平扩展。
  - 分布式租约锁保证定时任务跨副本只跑一个实例，冷启动建表互斥。
  - 两个离线迁移脚本把连接与 OIDC 配置自 env 迁入数据库，不覆盖已有值。
  - 种子账号告警仅在「首次登录强制改密未完成」时触发。
  - 新增 Kubernetes 参考清单。
  - OpenAPI 接口描述精简为「动作与行为」，字段清单与背景说明回归文档。
  - `resolve-tag` 只解析一次映射，不再重复全表遍历。
  - CI 相关文案补全所有受支持的引擎，并把 Custom_Push 描述为推送式接入通道（外部 CI 主动上报，Glue 不调度），而非 CI 引擎之一。
  - 「映射用哪条 CI」与「调用它用哪个 project id」各自只有一份定义，构建、scan-sync、commit-status 共用，三个端点不会再解析到不同行。
  - 新增 CI 数据流架构图，放入 README 与架构全景图，并附线型图例说明；文档图片统一收纳到 `docs/Image/`。
  - Docker 构建上下文排除 `docs/`：原有的 `*.md` 规则不跨路径分隔符，`docs/` 下的文档与配图此前仍会被发送给构建守护进程。
  - `config/app.env.staging` 补齐为完整的环境覆盖层模板：写明哪些键归本层、哪些属机密（指引写 `app.env.local`）、哪些已迁 DB（Jenkins / Git / Harbor / OIDC issuer，在本文件配也不生效）；生效行仍只有 `APP_DEBUG=true`，其余为注释示例。

## v2.9.0 (2026-10-15)

> **⚠️ 破坏性变更——v2.9.0 为重大更新，与旧版本不兼容。** 升级前请先查看[管理员配置手册](管理员配置手册.md)中的 CI↔CD 版本对应关系。
- **新增**
  - 部署日志改经 HTTP 从 CD 读取，不再读共享视图；CD 无法提供时页面降级为占位提示。
  - 集成服务可通过窄接口查询「是否启用」与建表方式；服务名不在白名单（404）与「未启用」严格区分。
  - Git Tag 可作为构建 ref，与既有的分支列表并列提供。
  - 集成服务启用契约化：启用即签发限定 scope 的凭据，禁用只是冻结、仅撤销才作废。
  - API Token 的 scope 可直接编辑，无需重新签发。
  - 面向 CD 的 OIDC 支持：按客户端判定账号归属、注册 cd 客户端、access token 以摘要存储、可查询角色权限。
  - 列结构与建表脚本对账，宽度只增的漂移自动对齐。
- **修复**
  - CD 不再回退直读共享契约表：问不到一律按「库不可用」返回 503，绝不静默等同于「未启用」。
  - CI 自有表统一 `ci_` 前缀并原地改名；改名前的备份仍可恢复，新旧表名混存的备份拒绝恢复。
  - 索引在自动迁移与手动建库两套脚本间完全一致；按驱动修正索引语法与列宽。
  - 日志中心「加载中…」不再与降级提示同屏残留。
  - token 有效期上报与真实有效期一致；反向代理场景必须显式配置 OIDC issuer。
  - 启用弹窗不再把 HTML 标签原样显示为文本。
  - OpenAPI 补录两个遗漏的日志端点，路径参数口径统一。
- **优化**
  - 移除 Grafana 单点登录客户端。
  - 文档补充「CI+CD 联合部署变量归属」与「裸机部署最小配置」，表名引用在手册间收口。

## v2.8.9 (2026-10-11)

- **新增**
  - 建库方式成为显式选择：由应用账号自动建库，或由发布流水线用特权账号跑迁移 CLI。
  - 迁移预检（dry-run）只预览待补的表与列、不写库，与实跑共用同一份事实且无需 DDL 权限。
  - 公开健康检查端点返回数据库可达性与版本状态，库不可达时返回 503。
  - 密码哈希支持 argon2id（默认仍为 bcrypt），存量哈希无需迁移即可继续校验。
  - 后台「系统信息」显示当前是自动还是手动建库模式。
- **修复**
  - 静态资源不再下发 30 天 immutable 缓存，升级后浏览器不再沿用旧 JS / CSS。
  - 后台「数据表清单」比真实库少一张表且无法被发现；清单现与真实表集合对账，并在运行时自检。
  - 回滚不再收窄系统角色权限；种子部分失败改为快速失败并留审计，不再播一半。
  - 版本跃迁与降级写入操作日志，去重键按渠道区分，引导与显式迁移各自可见。
  - schema 版本查询改用参数绑定。
  - 健康检查区分「库不可达」与「表结构尚未对齐」，滚动升级不再被整体摘流。
- **优化**
  - 容器默认剥离全部 capabilities，只回授必需项；本地 env 覆盖文件不再打进镜像。
  - 旧版 base64 文档令牌默认关闭。
  - 前端 DOM 输出统一转义；CI workflow 声明最小权限。
  - 用户手册补齐「镜像标签与日志设置」与「后台功能页总览」操作详解。

## v2.6.4 (2026-08-25)
