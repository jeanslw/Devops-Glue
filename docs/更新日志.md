# 更新日志

## v2.6.3 (2026-08-24)
- **LDAP 登录支持** — 新增基于 PHP ext-ldap 的 LDAP 认证（零新增 composer 依赖）：支持 `user_dn_pattern` 直连模式与 `bind_dn + base_dn + user_filter` 管理员搜索模式，支持 LDAPS / StartTLS，过滤器与 DN 均做转义防注入。
- **认证链整合** — `AdminAuthService` 登录顺序：本地 DB → LDAP → env 兜底；LDAP 验证通过后必须已在 `user_identities` 绑定本地账号，否则拒绝登录（`auth.ldap_not_bound`）；`ldap_bind_failed` / `ldap_user_not_found` 统一映射为「账号或密码错误」。
- **账号绑定表** — 新增 `user_identities` 身份源关联表（`provider_type + provider_uid` 全局唯一），支持 local / ldap 多身份源绑定；LDAP 身份 credential 恒为 NULL，登录成功后自动回刷 email 与 raw_profile。
- **admin_users 结构扩展** — 新增 `id`（BIGINT/INTEGER 自增主键）、`avatar_url`、`status`（1=启用, 0=停用）、`created_at` 字段；新库由 `mysql_init.sql` / `sqlite_init.sql` 一次性建全，存量库通过幂等 columnMigrations 自动补 `avatar_url` / `status` / `created_at` 三个普通列，**`id` 主键需部署方手动迁移**（MySQL AUTO_INCREMENT 主键列无法幂等 ALTER 补加，且涉及旧 username 主键变更）。
- **用户启用/停用（踢下线）** — 登录时校验 `admin_users.status`，停用（status=0）账号被拒绝登录；token 验证回查账号状态，停用后尚未过期的旧 token 立即失效。后台用户列表新增「状态」列与启停按钮（`PUT /api/admin/users/{username}/status`）；root 账号与自己不可被停用。
- **时间戳语义修正** — 创建用户时只写入 `created_at`，仅更新用户时才写入 `updated_at`。
- **CD 联动** — Devops_CD 登录与 token 校验同步 `status`（含列存在性回退，兼容旧库），与 CI 行为一致。
- **配置项** — `config/settings.php` 新增 `ldap` 配置段（enabled / host / port / use_tls / use_ldaps / base_dn / bind_dn / bind_password / user_filter / user_dn_pattern / attrs / network_timeout），`.env.example` 附完整注释示例；`APP_VERSION` 升级至 2.6.3。
- **错误提示翻译** — 中/英语言包新增 `auth.ldap_not_bound`、`auth.user_disabled`。

- **管理后台增强** — 新增 Custom_Push 状态卡片、自动发现扫描支持、下拉菜单和映射列表适配。
- **数据库新增** — 新增 `ci_custom_builds` 表存储构建元数据，`pipeline_iid` 为整数类型。
- **OpenAPI 文档** — 补全新接口的 OpenAPI 规范（中/英）。
- **文档更新** — API 文档、管理员手册、技术文档、架构图、FAQ 均同步更新。
- **版本对应关系** — Devops-Glue API v2.6 ↔ Devops-Glue CD v1.4。
- **版本更新** — 应用版本升级至 v2.6.0。
- **细节优化** — 上报记录分页（Custom_Push_Log）；未启用 Custom_Push 时新增 custom_push 映射降为待定并在所有构建模式过滤；Harbor 仓库与 tag 存在性区分校验；拓扑图数据流方向 git → build → harbor。

- **服务版本兼容性文档** — 新增《对接服务版本兼容性说明》（中/英），覆盖 Jenkins / GitLab / Gitea / Harbor 版本支持与边界。
- **CI 支持表述修正** — FAQ、管理员手册、架构图、API 文档统一表述：推送式 Custom_Push（理论上支持所有 CI）与拉取式 Jenkins / GitLab CI 并列。
